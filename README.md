# 🇮🇳 Independence Day Participation Dashboard

## 📊 Project Overview

This project showcases an interactive Power BI dashboard designed to analyze participation data from Independence Day events.

The dashboard provides insights into participants across different states, departments, events, and gender categories.

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- Interactive KPI Cards
- State-wise Participation Analysis
- Event-wise Participation Analysis
- Department-wise Analysis
- Gender Distribution Analysis
- Interactive Filters and Slicers
- Dynamic Data Visualizations

## 📊 Key Metrics

- Total Participants
- Absent Count
- Register Count
- Total Events
- Total States
- Average Age
- Average Feedback
- Participation Percentage
